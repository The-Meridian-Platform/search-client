## 🏛️ Обзор и архитектура

**Meridian Client** — официальное десктопное приложение для поискового движка **Meridian Search Platform** (`MeridianHost.Api`). Клиент предоставляет аналитику удобное рабочее место в стиле Cyber OSINT (Linear / Raycast) для проведения разведки, изучения находок, просмотра логов и работы с историей поисков.

Приложение спроектировано по строгому шаблону **Model-View-ViewModel (MVVM)** с использованием библиотеки `CommunityToolkit.Mvvm`:
- **Слабая связанность:** Чёткое разделение между XAML-представлением (Views) и логикой состояния (ViewModels).
- **Потокобезопасность:** Реактивная синхронизация коллекций через `BindingOperations.EnableCollectionSynchronization` при потоковом приёме сотен сообщений по gRPC.
- **Плавные микро-взаимодействия:** Кинематические анимации переходов между вкладками, выезда панелей, стирания текста (backspace) и поочерёдного улетания карточек.

```
                    ┌────────────────────────┐
                    │    Meridian Host       │
                    │   (.NET 10 Web API)    │
                    └───────────┬────────────┘
                                │
               ┌────────────────┴────────────────┐
     REST API (POST / GET)              gRPC HTTP/2 Streaming
  (Жизненный цикл сессий, история)    (События FindingDiscovered)
               │                                 │
               ▼                                 ▼
       [MeridianApiClient]             [MeridianStreamClient]
               │                                 │
               └────────────────┬────────────────┘
                                │
                                ▼
                       [SearchViewModel]
                                │ (Потокобезопасная коллекция)
                                ▼
                       [FindingItemViewModel]
                                │
                                ▼
                         [SearchView]
```

## 🚀 Ключевые модули и возможности

### 1. Интерактивный поиск целей (`SearchView`)
- **Указание цели:** Поддержка типов целей `Auto`, `Domain`, `IpAddress`, `Email` и `Username`.
- **Информационный HUD-бар:** Отображение реального таймера работы (`mm:ss.fff`), статуса сессии (`Ready`, `Pending`, `Running`, `Completed`, `Failed`) и счётчиков по категориям.
- **Информативные карточки находок:**
  - **DNS:** Цветовые бейджи типов (`A`, `AAAA`, `MX`, `TXT`, `NS`), IP-адреса, TTL и приоритет MX.
  - **WHOIS / RDAP:** Регистратор, статус домена, даты создания и окончания регистрации, код страны.
  - **Поддомены:** Найденные поддомены из Certificate Transparency логов (`crt.sh`) с указанием издателя и сроков действия сертификата.
  - **Веб-стек и технологии:** HTTP статус-коды (`200 OK`, `301`, etc.), заголовок страницы `<title>`, веб-сервер и движок, а также индикаторы безопасности (`HSTS`, `CSP`, `X-Frame`).
  - **Просмотр исходного JSON:** Раскрывающийся аккордеон с красиво отформатированным JSON и кнопкой копирования в буфер обмена.
- **Быстрая очистка:** Стремительное посимвольное стирание текста в полях ввода и эффект быстрого поочерёдного улетания карточек.

### 2. Раскрывающаяся панель фильтров
- Неоновая кнопка `+` с плавной анимацией вращения (45°).
- Мгновенная клиентская фильтрация по категориям и текстовый поиск по всем полям находок.

### 3. История поисковых сессий (`HistoryView`)
- Журнал всех ранее выполненных сессий разведки с датами и количеством находок.
- Мгновенное открытие и загрузка данных любой исторической сессии обратно в основной экран.
- Удаление ненужных сессий прямо из интерфейса.

### 4. Журнал логов (`LogsView`)
- Интерактивный консольный просмотрщик событий REST API, gRPC и Health Check в реальном времени.
- Фильтры по уровню (`Все`, `Инфо`, `Варнинги`, `Ошибки`, `Отладка`) и быстрый поиск.
- Копирование всех отфильтрованных логов в буфер обмена в один клик.

### 5. Настройки и мониторинг (`SettingsView`)
- Переключение базового URL шлюза (поддержка HTTPS `https://localhost:7013` и HTTP `http://localhost:5168`).
- Поддержка открытого HTTP/2 (`SocketsHttpHandler.Http2UnencryptedSupport`).
- Пинг бэкенда в реальном времени с выводом статуса соединения и задержки.

## ⚙️ Требования и запуск

- **ОС:** Windows 10 (Сборка 19041+) или Windows 11
- **SDK:** .NET 10.0 SDK
- **Среда разработки:** JetBrains Rider или Visual Studio 2022+

### Сборка и запуск:

```bash
# Сборка проекта
dotnet build MeridianClient.slnx

# Запуск приложения
dotnet run --project MeridianClient.csproj
```
