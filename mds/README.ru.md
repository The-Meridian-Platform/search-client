## 🏛️ Обзор и архитектура

**Meridian Client** — официальное десктопное приложение для поискового движка **Meridian Search Platform** (`MeridianHost.Api`). Клиент предоставляет аналитику комплексное рабочее место в стиле Cyber OSINT (Linear / Raycast) для проведения разведки, изучения находок, интерактивного исследования инфраструктуры через граф связей, управления проектами расследований и аудита телеметрии.

Приложение спроектировано по строгому шаблону **Model-View-ViewModel (MVVM)** с использованием библиотеки `CommunityToolkit.Mvvm`:
- **Слабая связанность:** Чёткое разделение между XAML-представлением (Views) и логикой состояния (ViewModels).
- **Потокобезопасность:** Реактивная синхронизация коллекций через `BindingOperations.EnableCollectionSynchronization` при потоковом приёме сотен сообщений по gRPC.
- **Плавные микро-взаимодействия:** Кинематические анимации переходов между вкладками, выезда панелей, стирания текста (backspace) и поочерёдного появления карточек.
- **Двухтемный интерфейс:** Полная поддержка тёмной (Cyber Dark) и светлой тем с мгновенной адаптацией цветов графа и миникарты.

```

                    │    Meridian Host       │

     REST API (POST / GET)              gRPC HTTP/2 Streaming
  (Жизненный цикл сессий, история)    (События FindingDiscovered)
               │                                 │

      [SearchViewModel]                  [GraphViewModel]

               │                                 │
               ▼                                 ▼
         [SearchView]                       [GraphView]
```

|---|---|---|
| **Платформа** | .NET 10 (`net10.0-windows`) | Высокопроизводительный рантайм C# с оптимизациями JIT |

## 🚀 Ключевые модули и возможности

### 1. Стартовый экран (Meridian Hub — `WelcomeWindow`)
- Полноэкранный стартовый хаб для управления сессиями и проектами расследований.
- **Быстрый старт:** Мгновенный запуск нового поиска, открытие сохранённых расследований (`investigations.json`) или импорт внешних файлов.
- Список последних расследований с поиском, фильтрацией и счётчиками целей/находок.
- Бесшовный возврат из рабочей области в Hub в один клик.

### 2. Интерактивный поиск целей (`SearchView`)
- **Указание цели:** Поддержка типов целей `Auto`, `Domain`, `IpAddress`, `Email` и `Username`.
- **Информационный HUD-бар:** Таймер работы (`mm:ss.fff`), статус сессии (`Ready`, `Pending`, `Running`, `Completed`, `Failed`) и счётчики по категориям.
- **Информативные карточки находок:**
  - **DNS:** Цветовые бейджи типов (`A`, `AAAA`, `MX`, `TXT`, `NS`), IP-адреса, TTL и приоритет MX.
  - **WHOIS / RDAP:** Регистратор, статус домена, даты создания и окончания регистрации, код страны.
  - **Поддомены:** Найденные поддомены из Certificate Transparency логов (`crt.sh`) с указанием издателя и сроков действия сертификата.
  - **Веб-стек и технологии:** HTTP статус-коды (`200 OK`, `301`, etc.), заголовок страницы `<title>`, веб-сервер и движок, индикаторы безопасности (`HSTS`, `CSP`, `X-Frame`).
  - **Просмотр исходного JSON:** Раскрывающийся аккордеон с красиво отформатированным JSON и кнопкой копирования в буфер обмена.

### 3. История поисковых сессий (`HistoryView`)
- Журнал всех ранее выполненных сессий разведки в хранилище PostgreSQL.
- Интеллектуальная фильтрация: изоляция сессий в рамках выбранного проекта расследования либо глобальный просмотр всей базы.
- Мгновенное открытие и загрузка данных любой исторической сессии обратно в основной экран или граф.
- Удаление ненужных сессий прямо из интерфейса.

### 4. Журнал логов (`LogsView`)
- Интерактивный консольный просмотрщик событий REST API, gRPC и Health Check в реальном времени.
- Фильтры по уровню (`Все`, `Инфо`, `Варнинги`, `Ошибки`, `Отладка`) и быстрый поиск.
- Копирование всех отфильтрованных логов в буфер обмена в один клик.

### 5. Настройки и мониторинг (`SettingsView`)
- Переключение базового URL шлюза (поддержка HTTPS `https://localhost:7013` и HTTP `http://localhost:5168`).
- Поддержка открытого HTTP/2 (`SocketsHttpHandler.Http2UnencryptedSupport`).
- Пинг бэкенда в реальном времени с выводом статуса соединения и задержки.
- Настройки поведения графа (слияние общих сущностей, автоматический расклад).

## 🕸️ Интерактивный граф связей и оптимизации (`GraphView`)

Граф связей Meridian Client предназначен для визуального исследования сложных цифровых следов (150+ узлов и 190+ связей, например `google.com`) с бескомпромиссной производительностью 60–120 FPS.

### Физический движок (Force-Directed Engine):
- **Сили отталкивания Кулона** между всеми узлами $O(N^2)$ с отсечением далеких пар ($>650$ px).
- **Пружины Гука** вдоль связей для формирования естественных кластеров.
- **Гравитационное центрирование** к середине холста.

### 4 ступени оптимизации Highload UI:
1. **Physics Auto-Sleep & Damping:**
   - Мониторинг суммарной кинетической энергии системы и лимита шагов (`MaxIterations = 140`).
   - При затухании колебаний таймер физики останавливается (`IsRunning = false`), снижая нагрузку на процессор до **0.0% CPU**.
   - Пробуждение (`WakeUp()`) происходит только при действиях пользователя (drag узла, Pivot, добавление находок).
   - При перетаскивании одного узла физика пересчитывается **локально** только для соседних связей.
2. **GPU-батчинг и WPF Freezing:**
   - Все кисти (`SolidColorBrush`), перья (`Pen`) и геометрии заморожены вызовом `.Freeze()`, позволяя WPF передавать примитивы напрямую в видеопамять без Dispatcher-отслеживания.
   - Пул линий связей (`_edgeLinesPool`): полное исключение пересоздания `Line` на каждый кадр, только обновление координат `X1, Y1, X2, Y2`.
3. **Level of Detail (LOD) при масштабировании:**
   - При отдалении холста (`ZoomScale < 0.55`) DirectWrite-текстовые метки узлов скрываются, оставляя чёткие цветные узлы и связи, что исключает затратный рендеринг шрифтов.
   - При приближении (`ZoomScale >= 0.55`) подписи мгновенно возвращаются.
4. **Лимиты безопасности холста (Canvas Safety Bounds):**
   - Установлен порог `MaxCanvasNodes = 200` узлов.
   - Защита холста от деградации FPS при разворачивании гигантских кластеров со статус-чипом предупреждения.

### Инструменты исследования графа:
- **Expand / Pivot по узлу:** Углублённый поиск связей по любому поддомену, IP-адресу или почте прямо из графа (двойной клик или контекстное меню).
- **Сворачивание / разворачивание веток:** Коллапсирование дочерних узлов в бейдж с количеством скрытых связей.
- **Подсветка маршрутов угроз (Threat Path Tracing):** Пульсирующая неоновая подсветка цепочки от опасного узла к целевым корням.
- **Интерактивная миникарта:** Обзор всего пространства графа с подсветкой видового экрана и возможностью навигации кликом/перетаскиванием.
- **Экспорт в High-DPI:** Сохранение графа в векторном или высоком растровом разрешении для отчётов.

## 📂 Структура проекта

```
MeridianClient/
├── App.xaml / App.xaml.cs                   # Точка входа, DI-контейнер, регистрация темы
├── MainWindow.xaml / MainWindow.xaml.cs     # Главное рабочее окно, сайдбар, переключение экранов
├── WelcomeWindow.xaml / .xaml.cs            # Стартовый хаб расследований (Welcome Hub)
├── MeridianClient.csproj                    # Конфигурация проекта и компиляция Protobuf
├── Converters/
│   └── ValueConverters.cs                  # Конвертеры значений (Visibility, Brush, String matching)
├── Models/
│   ├── AppSettings.cs                       # Настройки клиента
│   ├── GraphModels.cs                       # Модели узлов (GraphNode), связей (GraphEdge), типов
│   ├── InvestigationModel.cs                # Модель проектов расследований
│   ├── FindingModel.cs                      # Модель универсальной находки
│   ├── LogEntry.cs                          # Запись журнала событий
│   └── SearchSessionModel.cs                # Модель поисковой сессии
├── Services/
│   ├── GraphDataMapper.cs                   # Преобразование OSINT-находок в узлы и связи
│   ├── GraphSimulationEngine.cs             # Физический движок с Auto-Sleep и Local Physics
│   ├── InvestigationService.cs              # Персистентное хранение расследований в JSON
│   ├── MeridianApiClient.cs                 # Клиент REST API
│   ├── MeridianStreamClient.cs              # Клиент gRPC стриминга
│   ├── ThemeService.cs                      # Сервис динамического переключения Dark/Light тем
│   └── ToastService.cs                      # Система всплывающих уведомлений
├── ViewModels/
│   ├── GraphViewModel.cs                    # Управление графом связей, зумом, раскладками, Pivot
│   ├── HistoryViewModel.cs                  # Управление историей сессий с изоляцией расследований
│   ├── SearchViewModel.cs                   # Управление поиском целей и стримингом находок
│   ├── WelcomeViewModel.cs                  # Логика стартового хаба расследований
│   └── MainViewModel.cs                     # Главная ViewModel координации окон и экранов
└── Views/
    ├── GraphView.xaml / .xaml.cs            # Интерактивный холст графа связей и миникарта
    ├── HistoryView.xaml / .xaml.cs          # Экран истории сессий
    ├── LogsView.xaml / .xaml.cs             # Экран журнала логов
    ├── SearchView.xaml / .xaml.cs           # Экран поиска целей и карточек
    └── SettingsView.xaml / .xaml.cs         # Экран настроек
```

## ⚙️ Требования и запуск

- **ОС:** Windows 10 (Сборка 19041+) или Windows 11
- **SDK:** .NET 10.0 SDK
- **Среда разработки:** JetBrains Rider или Visual Studio 2022+

### Сборка и запуск:

```bash
# Сборка проекта
dotnet build MeridianClient.csproj

# Запуск приложения
dotnet run --project MeridianClient.csproj
```
